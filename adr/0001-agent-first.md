# Агент вместо команд, одна команда на инсталляцию, минимальный код

Status: Amended by 0002 (eval-набор, подтверждение кнопкой, миграции схемы)

Date: 2026-09-30

Context: цель — открытый Telegram-бот для небольших команд, которым могут пользоваться люди без инженерного опыта: развернул, дал токен Telegram и ключ модели, пользуешься. Код должен легко ревьюиться теми, кто доверит боту свои данные. Отвергнуто: детерминированный бот с командами, клавиатурами и FSM (много кода и жёсткий интерфейс); конвейер «классификатор → один интент → text-to-SQL» (одно сообщение не может содержать несколько действий, а изоляция данных держится на проверке сгенерированного SQL); мультитенантность (join-токены, middleware, Postgres ради одной команды).

Decision:
- **Вход — агент.** Любое сообщение в личке (текст или голос) идёт в один цикл с tool calling (Chat Completions, OpenAI-совместимый API). Одно сообщение может вызвать несколько tools («удалёнка; вчера X, сегодня Y»).
- **Tools — единственная поверхность действий** (`app/tools.py`): обычные функции, схема для модели генерируется из сигнатуры и docstring. Отправитель (`me`) подставляется кодом, модель его не выбирает; админские tools обычным участникам не показываются. Text-to-SQL нет — только типизированные read-tools.
- **Планировщик детерминированный** (`app/scheduler.py`): один тик в минуту, дедупликация через таблицу `sent`. Кнопки статуса в утреннем пинге — быстрый путь.
- **Одна инсталляция = одна команда.** Первый, кто написал `/start`, — админ; остальные входят по инвайт-ссылке.
- **Хранилище — SQLite** в Docker-томе, схема в `app/db.py`, без миграций.
- **Конфиг — только env** (`BOT_TOKEN`, `OPENAI_API_KEY` обязательны; `MODEL`, `OPENAI_BASE_URL`, `TRANSCRIBE_MODEL` опциональны). Всё поведенческое (часовой пояс, страна праздников, времена, админы, язык уведомлений) настраивается разговором с ботом и хранится в БД. Промпты — `app/prompts/*.md`, переопределяются копией в `DATA_DIR/prompts/`.
- **Установка — `install.sh`** (`curl … | sh`): ставит Docker, спрашивает два секрета, запускает образ из GHCR. Повторный запуск — обновление. CI гоняет тесты и публикует образ; SSH-деплой опционален (`DEPLOY_ENABLED`).
- **Фичи:** статусы, дейли (текст/голос), саммари, отпуска с одобрением, праздники, напоминания, вопросы по данным, ретро (текстом), недельные отчёты, заметки, объявления.
- Код, промпты и README — на английском; агент отвечает на языке собеседника, фиксированные уведомления — ru/en (`app/texts.py`).

Consequences:
- (+) ~1k строк Python и 4 зависимости (aiogram, openai, holidays, tzdata).
- (+) Ревьюеру достаточно прочитать `tools.py`, чтобы знать, что может ИИ; изоляция гарантируется кодом, а не промптом.
- (+) Составные сообщения и свободный язык; на одно сообщение обычно 1–2 вызова модели.
- (−) Поведение вероятностное. На `gpt-5.4-nano` при первом прогоне агент подтверждал изменения, которых не делал; лечится формулировкой результатов tools и правилом «подтверждай только результат tools», но нужен eval-набор и, возможно, модель посильнее по умолчанию.
- (−) Вторая команда = второй бот и вторая инсталляция.
- (−) Нет миграций схемы: изменение таблиц в будущем потребует простого механизма версий (например, `PRAGMA user_version`).
- (−) Первый написавший боту становится админом — до этого момента ссылку на бота не стоит публиковать.
